# Code of Conduct

Kami ingin proyek Hermas menjadi tempat yang inklusif, aman, dan profesional bagi siapa pun yang ingin berkontribusi.

- Bersikap hormat, terbuka terhadap kritik teknis, dan fokus pada ide/implementasi.
- Tidak melakukan pelecehan, intimidasi, hinaan pribadi, diskriminasi, atau membocorkan informasi pribadi.
- Jangan mempublikasikan password, token, kunci SSH, atau laporan celah keamanan yang belum ditangani.
- Maintainer dapat menghapus konten yang melanggar aturan, menutup diskusi, atau membatasi partisipasi.

Jika terjadi pelanggaran, gunakan jalur pelaporan privat ke maintainer (misalnya GitHub private vulnerability reporting jika terkait keamanan). Jangan gunakan Issue publik untuk membagikan data sensitif.
